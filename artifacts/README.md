# artifacts/ — результаты работы агентов

Здесь агенты складывают готовые артефакты. Одна задача = одна папка.

```
artifacts/
└── <название-задачи>/          например: osen-2026
    ├── _brief.md               чек-лист + статусы гейтов (заполняет оркестратор)
    ├── 1-analitika/            analyst
    ├── 2-koncepciya/           stylist-art-director
    ├── 3-vizual/               graphic-designer
    ├── 4-tehpaket/             technologist
    ├── 5-ekonomika/            analyst
    └── 6-upakovka/             graphic-designer + stylist-art-director
```

Правила:
- Папку этапа создаёт агент, когда этап стартовал.
- Файл артефакта = результат. Устный вывод без файла не считается сделанной работой.
- `_brief.md` — единственный источник правды по статусу задачи: что заказано, какие гейты пройдены.
- Задача закрыта — папка остаётся в истории, не удаляется.
