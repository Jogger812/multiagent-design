# Гравировка и паттерн — спецификация дебосса и фрагментации

> Точная механика того, как знак JS работает на металле в капсуле JS DARK. Глубина рельефа дана в относительных ступенях (мельче/глубже друг друга), а не в миллиметрах — точные допуски и параметры лазера/штампа под конкретный сплав это зона технолога, шаг 4.

---

## 1. Общий принцип: две стратегии, не смешивать на одной детали

Капсула использует ровно две стратегии работы со знаком (из четырёх, описанных стилистом в `stilevaya-ramka-dark-fashion.md`, раздел 3.7):

1. **Приглушение (дебосс, чёрное на чёрном)** — знак виден целиком, но громкость снижена. Применяется там, где знак — главный смысловой центр детали: пуговица, кожаная накладка, тканая этикетка.
2. **Фрагментация** — знак обрезан кромкой детали, целиком не показан. Применяется на второстепенных, более мелких носителях: собачка молнии, металлическая шильда, хэнгтег.

Кодирование (`DK.01` вместо `EST.2018`) и масштабирование вниз (звезда-маркер на хольнитенах) — две другие стратегии из той же рамки, разобраны отдельно в разделах 3 и 5.

**Правило, которое не нарушается ни на одной детали:** знак JS не смешивает обе стратегии одновременно. Либо он весь виден (приглушённо), либо обрезан (фрагментированно) — никогда «половина дебосс, половина фрагмент» на одном и том же контуре.

---

## 2. Глубина рельефа — относительная шкала

Три уровня глубины, от самого мелкого до самого глубокого. Уровень выбирается по роли элемента, не по вкусу:

| Уровень | Название | Роль | Где применяется |
|---|---|---|---|
| **0 — плоскость** | Полированная фаска / вершина | Самое светлое, ничего не углублено, чистый металл | Кромка детали, вершины рельефа |
| **1 — мелкий лазер** | Лазерная гравировка по сатину | Мелкий текст и коды, не механическая деформация — только оптический след | `DK.01`, серийные номера, штрихкод на хэнгтеге |
| **2 — стандартный дебосс** | Штамп/чеканка среднего заглубления | Основной знак JS там, где он приглушённо виден целиком | Пуговица, шильда (до обрезки кромкой), хэнгтег |
| **3 — глубокий штамп** | Структурная канавка / ребро | Не несёт текста, чисто конструктивный элемент | Канавка под `DK.01` на пуговице, торцевая накатка |

Обратный, выпуклый рельеф (эмбосс) в капсуле используется только один раз и только на звезде-маркере хольнитенов — стилист прямо ограничил его высотой «не более 0,3 мм»: это уже готовое числовое ограничение из рамки, я его не меняю и не увеличиваю ни на одной другой детали.

**Правило перепада внутри детали:** уровень 0 (фаска) и уровень 2 (дебосс знака) должны давать минимум 3 ступени по серой шкале при взгляде на деталь целиком — вершина светлая, поле среднее, впадина знака тёмная. Наглядно — в HTML-визуализации, блок «Правило контраста».

## 3. Композиция пуговицы — `DK.01` целиком

Пуговица, 17 мм, вид сверху, по кольцевым зонам от края к центру:

```
┌─────────────────────────────┐
│  ░░░ накатка (торец) ░░░     │  ← уровень 0, кромка, рифление
│ ┌───────────────────────┐   │
│ │  фаска (полированная)  │   │  ← уровень 0, узкое кольцо ~8% радиуса
│ │ ┌───────────────────┐ │   │
│ │ │   сатин-поле        │ │   │  ← уровень 0 (фон), среднее по светлоте
│ │ │                     │ │   │
│ │ │        JS           │ │   │  ← уровень 2, дебосс, чёрное на чёрном
│ │ │                     │ │   │
│ │ │   ───────────────   │ │   │  ← уровень 3, структурная канавка
│ │ │       DK.01          │ │   │  ← уровень 1, лазер по сатину
│ │ └───────────────────┘ │   │
│ └───────────────────────┘   │
└─────────────────────────────┘
```

**Порядок по вертикальной оси, сверху вниз:**
1. Верхняя треть — пустое сатин-поле (по правилу стилиста «вокруг знака должно оставаться пустое поле не менее половины его высоты» — здесь оно даже больше половины, потому что низ занят индексом).
2. Центр — знак JS, дебосс уровня 2, тон-в-тон с полем (не темнее и не светлее осознанно — различим только по перепаду теней на вершинах и во впадинах букв).
3. Сразу под знаком — одна тонкая горизонтальная канавка уровня 3, во всю ширину пояса знака (не во всю пуговицу — не превращается в кольцо-рамку). Это единственный конструктивный элемент, который в старой раскладке был круговым обрамлением; здесь он распрямлён в прямую линию и не несёт текста.
4. Нижняя четверть — `DK.01` уровня 1 (лазер, самый мелкий и самый плоский из применённых уровней — код капсулы физически «легче» самого знака, что верно иерархически: знак важнее кода).

**Типографика индекса:** моноширинный, кегль примерно 1/5 высоты знака JS, трекинг +20% (в диапазоне 15–30%, заданном стилистом), точка в `DK.01` — не декоративный разделитель, а стандартный десятичный код капсулы, читается как заводская маркировка партии.

**Что убрано и не восстанавливается ни в каком виде:** дуговой текст, слово «EST», обрамляющее кольцо-рамка вокруг знака.

## 4. Направление и угол фрагментации — системное правило

Фрагментация в капсуле не произвольна для каждой детали — она подчиняется одному системному правилу:

**Все срезы (и композиционные, и те, что обрезают знак) идут по одной и той же диагонали — 45°, из нижнего правого угла в верхний левый — на любой прямоугольной детали капсулы.**

Это значит: срезанный угол на кожаной накладке, срезанный угол на металлической шильде и срезанный угол на хэнгтеге — не три независимых решения об асимметрии, а один и тот же вектор, повторённый на трёх носителях. Деталь получает асимметрию один раз и по всей капсуле одинаково — то есть выполняется требование стилиста «асимметрия работает только как системное решение, не как случайность» (раздел 1.6 `elementy-stilistiki-i-dnk-brenda.md`).

**Как это работает с логотипом на шильде:** линия среза угла — это одновременно и линия, которой обрезан знак JS. Знак размещён так, что его правая нижняя четверть (нижняя часть буквы S) попадает ровно в отрезанную зону. На детали остаётся: полная вертикаль J, верх и середина S, звезда рядом с ней — целиком; отрезано — нижний завиток S, примерно 25–30% площади знака. Смотрящий, знакомый с брендом, достраивает букву S в уме — это и есть механика фрагментации по стилисту («знает тот, кто уже знает бренд»).

**Как это работает на хэнгтеге:** тот же угол, тот же вектор среза, но здесь обрезается не сам знак, а звезда-маркер рядом с ним — виден только один луч звезды у самой кромки, сам знак JS остаётся целым чуть выше и левее среза. Причина разной механики: на шильде знак — единственный графический элемент, обрезка звезды была бы незаметна; на хэнгтеге рядом есть ещё код и штрихкод внизу, поэтому обрезается более декоративный, а не более смысловой элемент.

**Как это работает на собачке молнии:** деталь настолько мала (18×9 мм), что обрезается не буква целиком, а её характерный фрагмент силуэта — верхняя часть вертикали J, читаемая как узнаваемый «обрубок» знака, а не как случайная линия. Угол среза здесь — тот же 45°, но приложен к короткой стороне детали (кромка затяжки), не к длинной, как на прямоугольных элементах — деталь слишком мала, чтобы нести полноразмерный срезанный угол без потери формы затяжки.

## 5. Хольнитены — почему здесь не фрагментация и не дебосс, а «кодирование вниз»

Отдельно поясняю, почему хольнитены (9 мм) не подчиняются двум основным стратегиям раздела 1. При таком диаметре ни полноразмерный дебосс знака, ни его читаемая фрагментация физически не помещаются без потери качества гравировки (лазер «замыливает» мелкие детали на такой площади). Поэтому здесь используется четвёртая стратегия рамки — масштабирование вниз: знак заменён на его минимальный узнаваемый остаток — перерисованную звезду-маркер, уровень рельефа 1 (лазер по сатину), без текста вообще. Это не нарушение системы, а её честный предел: 9 мм — граница, ниже которой ни дебосс, ни фрагментация уже не работают.

## 6. Паттерн-фон — гильош вместо камуфляжа

Фоновый паттерн на кожаной накладке (позиция 4) меняется с органического «камуфляжного» на **гильош** — регулярную волновую микрогравировку, как на банкноте или монетном поле.

**Почему гильош, а не микро-растр или шум (два других варианта из библиотеки фактур стилиста):** гильош одинаково хорошо переносится и на кожу (тиснением), и на металл (если понадобится единый паттерн-фон и на шильде) — то есть один графический паттерн-модуль работает на двух разных материалах капсулы без адаптации. Микро-растр и шум визуально более «плоские» и не дают того самого эффекта «тёмный финиш на волнистой поверхности», который стилист прямо называет ключевым отраслевым трендом FW26-27 (AMC).

**Параметры паттерна (относительные, не в мм):**
- Направление волны — горизонтальное, шаг регулярный, без градиента плотности (в отличие от «дыма/копоти» из раздела 1.5 стилевой рамки — это отдельный, состаривающий приём, здесь не используется).
- Амплитуда волны — минимальная, паттерн не должен спорить со знаком JS в дебоссе по нему: гильош — это шум поля, а не второй смысловой слой.
- Зона нанесения — вся площадь накладки, кроме зоны знака JS и зоны подписи `EST.2018` в углу: там паттерн прерывается, поле остаётся гладким (пустота вокруг знака работает и здесь).

## 7. Сводное правило для технолога (передаётся, не решается здесь)

Три относительных уровня глубины (плоскость / лазер / дебосс / глубокий штамп — 4 названных, 3 «врезных») нужно перевести в конкретные допуски под сплав (латунь для пуговицы и шильды, ЦАМ для собачки молнии) и метод (штамп vs лазер vs гравировка по коже). Точные миллиметры глубины, углы фрезы, стойкость дебосса к истиранию — это решение шага 4, не шага 3.
