## 1. Объём работы

Быстрый выбор — один пресет. Или пропусти и собери свой набор в разделе 2.

- [ ] **A. Только дизайн** — концепция и визуал. Агент: graphic-designer
- [ ] **B. Дизайн + производство** — A плюс тех-эскиз, описание, себестоимость. Агенты: graphic-designer, technologist
- [ ] **C. Дизайн + производство + рынок** — B плюс тренды, конкуренты, цена. Агенты: + analyst
- [ ] **D. Полный цикл** — C плюс концепция коллекции, стратегия запуска, коммерческая упаковка. Агенты: все 4

## 2. Материалы на выходе

Отметь конкретные артефакты. Пресет из раздела 1 проставляет галочки автоматически — можно снять лишние или добавить недостающие.

### analyst — рынок и цифры
- [ ] Анализ ЦА
- [ ] Конкурентный анализ
- [ ] Тренды (новые бренды, аномальный спрос/рост)
- [ ] Гипотезы
- [ ] Ассортиментная матрица
- [ ] Ценовая политика
- [ ] Юнит-экономика

### stylist-art-director — концепция и стиль
- [ ] Концепция коллекции
- [ ] История коллекции (нарратив)
- [ ] Стратегия запуска
- [ ] Этапы выхода на рынок
- [ ] Референсы для фотосъёмки

### graphic-designer — визуал и графика
- [ ] Мудборд
- [ ] Цветовая линейка
- [ ] Концепция и айдентика
- [ ] Размерная сетка
- [ ] Инфографика
- [ ] Рич-контент
- [ ] Знаковая система
- [ ] Промо-материалы
- [ ] Визуализация упаковки

### technologist — производство
- [ ] Тех-эскиз
- [ ] Техническое описание
- [ ] Спецификация фурнитуры
- [ ] ТЗ на производство
- [ ] Расчёт себестоимости
- [ ] Чек-лист создания коллекции
- [ ] Визуализация изделия / фурнитуры

## 3. Маршрут (заполняет оркестратор после выбора Ивана)

Собирается из отмеченного выше с учётом зависимостей (`WORKFLOW.md` → «Матрица зависимостей»). Независимые шаги идут параллельно.

| Шаг | Агент | Артефакты | Гейт | Статус |
|---|---|---|---|---|
| 1 | | | | ⬜ |
| 2 | | | | ⬜ |

⬜ не начат · 🔄 на утверждении · ✅ утверждён · ↩️ на доработке

---

## Пример: «забрендируй фурнитуру для джинс»

Оркестратор показывает три варианта объёма:

- **Быстро** — graphic-designer: концепция брендирования + визуализация фурнитуры. Один шаг, один гейт.
- **С производством** — плюс technologist: тех-эскиз, спецификация фурнитуры, себестоимость. Два шага, гейт после дизайна.
- **С рынком** — плюс analyst: тренды фурнитуры и конкуренты параллельно дизайну, дальше технолог.

Стилист в этой задаче не нужен — коллекцию не разрабатываем. Оркестратор его не подключает и не спрашивает про него.
